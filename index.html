Why Harmony

A familiar interface for a small community, without handing the community to a platform.

You own it

Messages, images and member data live on your hardware under your rules. No ID verification, no ads, no analytics, no terms of service but your own.

Migrating doesn't mean leaving

The bridge mirrors messages, replies, reactions, edits and deletes both ways with Discord. The setup wizard imports your channels and custom emoji for you.

Small on purpose

One process and one folder you can back up. No database server, no Docker, no cloud account. It fits on a Raspberry Pi or the cheapest VPS.

Feels like home

Pick a background and an accent colour and the whole interface follows. Install it to a phone or desktop home screen like a real app.

What it isn't. There are no direct messages and no friend list. One instance is one server. It is built to be a home for a community, not a platform.

# general

Install

You need Node.js 24 or newer. That is the only dependency.

  1. Run it locally

    From the project folder:

    npm install npm run dev

    Open http://127.0.0.1:5173 and register. It listens on loopback only, so nobody else can reach it yet.

  2. Create the owner account

    The first account you register becomes the owner, and a short wizard asks for a name and colours, storage settings, and whether to import from Discord.

    Do this before the instance is reachable from the internet. Until then, anyone who can reach it can claim the owner account.

  3. Build for production

    One Node process serves the client, the API and the WebSocket gateway. All state lives in data/.

    npm ci npm run build:web npm start

  4. Put it behind HTTPS

    Point a reverse proxy at 127.0.0.1:8787. With Caddy, certificates and WebSockets are handled for you:

    chat.example.com { encode zstd gzip reverse_proxy 127.0.0.1:8787 }

    Then set these in .env and restart:

    HARMONY_TRUST_PROXY=true HARMONY_COOKIE_SECURE=true

  5. Open the voice ports

    Voice chat is optional and needs UDP, which the HTTPS connection the rest of Harmony uses cannot carry. The media relay sends audio straight to the Node process, so your reverse proxy needs no changes, but the range has to be open on the host and in your provider's firewall:

    sudo ufw allow 40000:40100/udp

    The default range holds about a dozen simultaneous connections. Widen it with HARMONY_VOICE_PORT_MIN and HARMONY_VOICE_PORT_MAX for larger or busier rooms, and set HARMONY_VOICE_PUBLIC_IP if the host sits behind another NAT.

  6. Back it up

    Everything that matters is in data/. Copy it while stopped, or take a consistent copy while running:

    sqlite3 data/harmony.db ".backup '/backup/harmony.db'" cp -a data/uploads /backup/uploads
